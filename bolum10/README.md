# Bölüm 10 Ödevi — Karekök hesaplama

`prompt` ile alınan sayının karekökünü hesaplayan basit sayfa.

## Mantık

1. `prompt` ile değer al.
2. `Number()` ile sayıya çevir.
3. Boş / sayı değil / negatifse uyarı ver.
4. `Math.sqrt()` ile karekökü hesapla ve yazdır.

## Çalıştırma

`index.html` dosyasını tarayıcıda aç, "Karekök Hesapla" butonuna bas.
