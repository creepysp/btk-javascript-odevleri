# Bölüm 14 Ödevi — Hata Yönetimi

`prompt`, `throw` ve `try/catch` kullanan basit örnek.

## Senaryo

Kullanıcıdan 1–100 arası bir not iste. Girilen değer:
- boşsa → hata
- sayı değilse → hata
- 0'dan küçük veya 100'den büyükse → hata

Hata `throw` ile fırlatılır, `try/catch` ile yakalanıp `finally` ile temizlik yapılır.
