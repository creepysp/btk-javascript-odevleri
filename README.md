# BTK Akademi — Javascript Temelleri Ödevleri

Bu repo, **Javascript Temelleri** eğitimindeki bölüm ödevlerinin basit çözümlerini içerir.

## İçerik

| Klasör | Ödev | Ne var? |
|---|---|---|
| `bolum3/` | Bölüm 3 Ödevi | Küp ve büyük sayı algoritmalarının akış diyagramları (Mermaid) + pseudo kod |
| `bolum7/` | Bölüm 7 Ödevi | 1–5 milyon arası sayı yazdırma: hangi döngü, neden? + örnek kod |
| `bolum10/` | Bölüm 10 Ödevi | `prompt` ile alınan sayının karekökünü hesaplayan basit sayfa |
| `bolum14/` | Bölüm 14 Ödevi | `prompt` + `throw` + `try/catch` ile hata yönetimi örneği |

## Çalıştırma

- `bolum10/index.html` ve `bolum14/index.html` → tarayıcıda aç, yeter.
- `bolum7/dongu.js` → `node bolum7/dongu.js`

## Not

Akış diyagramları GitHub'da Mermaid olarak otomatik çizilir; ekstra araç gerekmez.
